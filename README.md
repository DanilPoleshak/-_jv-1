# Моделирование экосистемы «Растения — травоядные — хищники»

Учебный проект по моделированию искусственной жизни. Программа реализует разработанный студентом алгоритм взаимодействия растений, травоядных и хищников в двумерной клеточной среде.

Основная цель — подобрать параметры, при которых все три вида сохраняются в экосистеме не менее **1000 итераций**.

## Описание модели

Среда представлена двумерным массивом ячеек. Каждая ячейка может быть пустой или содержать одного агента:

- растение;
- травоядное;
- хищника.

Агенты взаимодействуют в соответствии с пищевой цепочкой:

Растения → Травоядные → Хищники

Каждый агент обладает запасом энергии. Поведение животных определяется логическими условиями, учитывающими их состояние и окружение.

## Основные правила

### Энергия и питание

- Травоядные и хищники расходуют энергию на каждом шаге моделирования.
- Травоядные восполняют энергию, поедая растения.
- Хищники восполняют энергию, поедая травоядных.
- При достижении нулевого запаса энергии агент погибает и удаляется из среды.

### Перемещение и восприятие

Животные воспринимают окружение в области 5 × 5 клеток. На основе доступной информации и заданных логических условий они выбирают дальнейшие действия, включая перемещение и питание.

### Размножение

При превышении установленного порога энергии агент создаёт потомка и передаёт ему часть своего энергетического запаса.

## Структура программы

Для реализации модели предусматриваются классы среды и агентов.

### Среда

Отвечает за:

- хранение двумерной сетки;
- размещение агентов;
- получение информации о содержимом ячеек;
- выполнение шагов моделирования;
- добавление и удаление агентов.

### Агенты

Описывают состояние и поведение растений, травоядных и хищников.

В зависимости от типа агента предусматриваются методы:

- перемещения;
- питания;
- размножения;
- изменения запаса энергии;
- удаления из среды при гибели.

## Этапы разработки

1. Разработка консольной версии для проверки алгоритма и подбора параметров.
2. Проведение экспериментов для поиска устойчивого режима существования экосистемы.
3. Разработка оконной версии для визуального отображения среды и взаимодействия агентов.

## Подбор параметров

В ходе экспериментов необходимо исследовать влияние параметров модели, в том числе:

- размеров среды;
- начального количества агентов каждого вида;
- начального запаса энергии;
- расхода энергии за один шаг;
- количества энергии, получаемой при питании;
- порога размножения;
- доли энергии, передаваемой потомку.

## Критерий успешности

Моделирование считается успешным, если растения, травоядные и хищники сохраняются в среде не менее 1000 последовательных итераций.

Это означает, что на протяжении указанного периода ни один из трёх видов не исчезает полностью. Постоянная численность популяций при этом не требуется.

## Интерфейс

- Предварительная версия — консольное приложение.
- Окончательная версия — оконное приложение с визуализацией экосистемы.
